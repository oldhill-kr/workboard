# 업무보드

옵시디언 `Work/업무/*.md` 노트를 카드·달력으로 보여주고 고쳐 쓰는 로컬 웹 앱입니다.
데이터의 원본은 옵시디언 노트이며, 이 저장소에는 **코드만** 있습니다. 개인 업무 내용은 올라가지 않습니다.

## 다른 PC에서 쓰기

1. 이 저장소를 받습니다.
   ```
   git clone <저장소 주소> 업무보드
   cd 업무보드
   ```
2. 의존 패키지를 설치합니다 (Python 3.10 이상).
   ```
   pip install -r requirements.txt
   ```
3. `config.example.json`을 `config.json`으로 복사하고 **이 PC의 `work_dir`** 를 고칩니다.
   옵시디언 볼트(OneDrive 등으로 동기화된 `Work` 폴더) 경로여야 합니다.
4. 실행합니다.
   ```
   python server.py
   ```
   브라우저에서 http://127.0.0.1:8765 를 엽니다.

## PC마다 따로인 것 / 같이 쓰이는 것

| 항목 | 저장 위치 | 다른 PC와 |
|---|---|---|
| 업무 내용, 상태, 마감, 보관 여부 | 옵시디언 노트 | 볼트 동기화로 공유 |
| 프로젝트 색 | 볼트 `Work/.업무보드-색상.json` | 볼트 동기화로 공유 |
| 볼트 경로, 구글 캘린더 주소, 알림 시각 | `config.json` | **PC마다 따로** (저장소에 올리지 않음) |
| 다크/라이트 모드 | 브라우저 | PC마다 따로 |

- 두 PC에서 동시에 켜 두면 **알림(아침·퇴근·금요일)이 양쪽에서 모두** 뜹니다. 한쪽 PC의 `config.json`에서 `"alarms": {}`로 비워 두세요.
- 두 PC가 같은 노트를 동시에 고치면 OneDrive 충돌 파일이 생길 수 있습니다. 한 번에 한 PC에서 쓰는 걸 권장합니다.


## 웹 버전 (서버 없이 브라우저에서만)

`index.html`은 서버(`server.py`)가 없는 곳(GitHub Pages 등)에서 열면 자동으로 **웹 모드**로 동작합니다.
이때 데이터는 사용자가 고른 저장 위치에만 저장되고, 사이트 서버로는 전송되지 않습니다. 처음 열면 저장 위치를 고릅니다.

| 선택 | 저장 위치 | 다른 PC에서 | 비고 |
|---|---|---|---|
| A. 이 브라우저 (로컬) | 브라우저 IndexedDB | 안 보임 (백업 파일로 이동) | 가장 간단 |
| B. 구글 드라이브 | 내 드라이브의 `업무보드 데이터` 폴더 | 구글 로그인만 하면 같은 데이터 | OAuth 클라이언트 ID 필요 |
| C. 옵시디언 / PC 폴더 | 고른 폴더의 `.md` 노트 (`업무/` 하위) | 같은 폴더가 있는 PC에서 | Chrome·Edge 전용 |

웹 모드에서 달라지는 점: 구글 캘린더(iCal) 연동 없음, 알림은 브라우저 알림(탭이 열려 있을 때만), 공휴일은 내장 데이터(2025~2027).

### 구글 드라이브(B) 설정 — 배포하는 사람이 한 번만
1. Google Cloud Console에서 프로젝트를 만들고 **Google Drive API**를 사용 설정합니다.
2. **OAuth 동의 화면**을 만들고(외부), 범위에 `.../auth/drive.file`(이 앱이 만든 파일만)을 추가합니다. 테스트 중이면 사용할 구글 계정을 "테스트 사용자"로 추가합니다.
3. **사용자 인증 정보 → OAuth 클라이언트 ID(웹 애플리케이션)** 를 만들고, "승인된 JavaScript 원본"에 사이트 주소(예: `https://<계정>.github.io`)를 넣습니다.
4. 발급된 클라이언트 ID를 `web/config.js`의 `googleClientId`에 넣거나, 사용자가 저장 위치 화면에서 직접 입력합니다. (클라이언트 ID는 공개돼도 되는 값입니다.)

### 로컬에서 웹 모드 시험
```
python -m http.server 8800
```
그리고 http://127.0.0.1:8800/index.html 을 엽니다. (`/api`가 없어서 웹 모드로 동작)

## 구성

- `server.py` : 표준 `http.server` 기반 서버 + 알림 + 노트 읽기/쓰기 API
- `index.html` : 화면 전체 (순수 JS, FullCalendar CDN). 서버가 없으면 웹 모드
- `web/core.js` : 웹 모드의 서버 역할 (노트 읽기·쓰기, 보관, 이름 변경, 색 고정 …)
- `web/adapters.js` : 저장소 어댑터 3종 (로컬 / 구글 드라이브 / 폴더)
- `web/holidays.js`, `web/config.js` : 공휴일 데이터, 구글 클라이언트 ID 설정
- `업무보드 실행.bat` : Windows에서 서버가 꺼져 있으면 켜는 실행 파일 (Python 경로는 PC에 맞게 수정)

설계와 변경 이력은 옵시디언 `Work/참고/업무보드 - 개발 기록 및 설계 노트.md`에 있습니다.
