# 업무보드

옵시디언 `Work/업무/*.md` 노트를 카드·달력으로 보여주고 고쳐 쓰는 로컬 웹 앱입니다.
데이터의 원본은 옵시디언 노트이며, 이 저장소에는 **코드만** 있습니다. 개인 업무 내용은 올라가지 않습니다.

## 다른 PC에서 쓰기

1. 이 저장소를 받습니다.
   ```
   git clone <저장소 주소> 업무보드
   cd 업무보드
   ```
2. 의존 패키지를 설치합니다 (Python 3.10 이상).
   ```
   pip install -r requirements.txt
   ```
3. `config.example.json`을 `config.json`으로 복사하고 **이 PC의 `work_dir`** 를 고칩니다.
   옵시디언 볼트(OneDrive 등으로 동기화된 `Work` 폴더) 경로여야 합니다.
4. 실행합니다.
   ```
   python server.py
   ```
   브라우저에서 http://127.0.0.1:8765 를 엽니다.

## PC마다 따로인 것 / 같이 쓰이는 것

| 항목 | 저장 위치 | 다른 PC와 |
|---|---|---|
| 업무 내용, 상태, 마감, 보관 여부 | 옵시디언 노트 | 볼트 동기화로 공유 |
| 프로젝트 색 | 볼트 `Work/.업무보드-색상.json` | 볼트 동기화로 공유 |
| 볼트 경로, 구글 캘린더 주소, 알림 시각 | `config.json` | **PC마다 따로** (저장소에 올리지 않음) |
| 다크/라이트 모드 | 브라우저 | PC마다 따로 |

- 두 PC에서 동시에 켜 두면 **알림(아침·퇴근·금요일)이 양쪽에서 모두** 뜹니다. 한쪽 PC의 `config.json`에서 `"alarms": {}`로 비워 두세요.
- 두 PC가 같은 노트를 동시에 고치면 OneDrive 충돌 파일이 생길 수 있습니다. 한 번에 한 PC에서 쓰는 걸 권장합니다.

## 구성

- `server.py` : 표준 `http.server` 기반 서버 + 알림 + 노트 읽기/쓰기 API
- `index.html` : 화면 전체 (순수 JS, FullCalendar CDN)
- `업무보드 실행.bat` : Windows에서 서버가 꺼져 있으면 켜는 실행 파일 (Python 경로는 PC에 맞게 수정)

설계와 변경 이력은 옵시디언 `Work/참고/업무보드 - 개발 기록 및 설계 노트.md`에 있습니다.
